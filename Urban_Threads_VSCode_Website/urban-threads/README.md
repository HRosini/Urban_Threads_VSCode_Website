# Urban Threads — BA0013L Student Website

A responsive demo clothing e-commerce website made with HTML, CSS and JavaScript.

## How to open in VS Code
1. Extract the ZIP file.
2. Open VS Code, then choose File > Open Folder > urban-threads.
3. Open index.html using the Live Server extension (right-click > Open with Live Server), or open index.html directly in your browser.

## Files
- index.html — page structure and content
- style.css — colors, layout, responsiveness
- script.js — products, filtering, demo shopping cart, contact mailto

## Important
This is a **demo**, not a live store. Product prices are examples. Cart data lasts only until page refresh. Checkout is disabled. The contact form opens an email draft without a destination address; add your real store email in script.js when available. Product illustrations are emoji placeholders; replace with licensed or original product photos before launch.

For your final project documentation, add real screenshots of the website and your public deployment URL after publishing to a static host such as GitHub Pages or Netlify.
